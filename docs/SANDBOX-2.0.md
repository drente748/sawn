## ما أنجز
- **نسخة 2.0.0 / versionCode 19** مهيأة؛ توقيف كامل (v2/v3)
- **إطار الدفع/الإعلانات/التحديث**:
  - `ads/AdsController.kt` — عقد إعلان معطل: **لا شيء لأي مستخدم**. النموذج المستقبلي: إعلانات شبكات خارجية (Google Mobile Ads) **فقط لمن لم يدفع**، ومحوها بالاشتراك
  - `entitlement/EntitlementService.kt` — تصنيف FREE/PAID + Noop (كامل الميزات مجاني اليوم). التوزيع المخطط للنسخة المدفوعة من موقع المالك مباشرة (ليس شرطًا عبر بلاي)، مع دعم اختياري للبلاي لاحقًا
  - `update/UpdateChecker.kt` — عقد + `RemoteManifestUpdateChecker` معطل بالكامل (لا اتصال، لا تبعية شبكة)
  - `di/AppModule.kt` — نقاط حقن موحدة (`entitlementService`, `updateChecker`, `adsController`)؛ تفعيل مستقبلي = استبدال التنفيذ هنا فقط
  - `docs/PLAY_COMPLIANCE.md` — فصل جديد "8): البنية المعطلة مسبقًا": تصريح أمانة + شروط تفعيل الإعلان والاشتراك (تحديث PRIVACY.md، تصريح بلاي + Data Safety، زر إزالة إعلانات، إعلان السعر قبل الميزة المدفوعة)
- **وثائق**: `PRIVACY.md` (سياسة خصوصية عربية)، `CHANGELOG.md` (مفصّل 2.0.0)، `PROGRESS-2.0.md` (دليل الإنجاز)، `install-ar.md` / `install-en.md` (دليل تثبيت APK + إعدادات مقيدة Android 13+)

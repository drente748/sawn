# خريطة الميزات — Sawn (صَوْن)

> الجرد **من الشيفرة**، لا من الرؤية. كل بند يذكر مكانه في المستودع، وحالاته، وما يجب أن
> يظهر في الواجهة. الغرض: أن تكون هذه الورقة مرجعاً واحداً لمرحلة التصميم والثيم.
>
> آخر تحديث: 2026-11-12 — بعد «القفل الفوري» (`6337ea6`).

---

## 0. النموذج العام

التطبيق يعمل بطبقتين مستقلتين، فلا نقطة انسحاب واحدة:

| الطبقة | المحرك | ما تغطّيه | الأذونات |
|---|---|---|---|
| **الشبكة** | `SawnVpnService` | كل المواقع في كل المتصفحات والتطبيقات | `VpnService` (إذن اتصال محلي) |
| **التطبيق** | `AppBlockAccessibilityService` | التطبيقات + شرائح داخل التطبيقات + شريط العنوان | `AccessibilityService` |

الفصل مُدار في `BlockCoordinator` / `ProtectionPolicy` (`core/domain/block/`)، وحالة
الطبقات تُقرأ من `SawnEngines` — فلا تسأل الواجهة «هل الحماية تعمل؟» بل «أي طبقة تعمل؟».

**وضعان للحماية** (`ProtectionMode`):

| الوضع | ما يعمل | ما لا يعمل | التكلفة |
|---|---|---|---|
| **متقدّم** (FULL) | DNS + وصول | — | يستهلك البطارية + إذن VPN |
| **عادي** (LIGHT) | وصول فقط | الفلترة على مستوى الشبكة (SafeSearch، DoH، إعلان) | بلا إذن VPN |

الشارة على الشاشة الرئيسية تقول الوضع **الفعلي الآن**، لا Mode المخزَّن.

**التسمية**: «كامل/خفيف» ← **«متقدّم/عادي»**.

**من يملك مفتاح فلترة DNS؟** المستخدم — دائماً. حتى أثناء القفل الزمني (يبقى الحجب على
مستوى التطبيق، لكن إطفاء فلترة DNS مسموح مع تنبيه). **الاستثناء الوحيد** هو **القفل
الفوري**: عند تفعيله يشغّل الوضع المتقدّم تلقائياً إن كان إذن VPN موجوداً (بلا مطالبة)،
ويبقى المستخدم حرّاً في إطفائه بعد ذلك.

**وضع الانضباط أُلغي** مع وضع وليّ الأمر: الأقفال نفسها تطلب PIN عند تفعيلها، وهي
التي تمنع الإيقاف. لا وضع دائم ولا رمز ثانٍ.

## 1. الحجب —Blocking

### 1.1 فلترة DNS (المحرك الأول)

| | |
|---|---|
| **الوظيفة** | يعترض استعلامات DNS داخل نفق محلي، ويجيب `0.0.0.0` (blackhole) للنطاقات المحجوبة، ويمرّر الباقي إلى محلّل الجهاز |
| **الملفات** | `app/vpn/SawnVpnService.kt`، `core/domain/vpn/DnsPacket.kt` |
| **الحالات** | النفق يعمل / متوقف / بلا إذن VPN / بلا محلّل قابل للاستخدام |
| **السطح** | مفتاح «الحماية» في الشاشة الرئيسية + حالة VPN في الإعدادات + إشعار النفق الدائم |
| **ملاحظات تصميم** | DNS-over-HTTPS يُحجب اختيارياً (`DohHosts`)؛ IPv6 له مساره الخاص؛ الحالة الحقيقية من `SawnVpnService.runningFlow` لا من المفتاح |

### 1.2 قوائم الحجب

| القائمة | المصدر | التحديث |
|---|---|---|
| **محتوى البالغين** | `AdultHosts` + `AdultListFetcher` (قوائم عامة على GitHub) | يدوي، عبر HTTPS، يُتحقَّق من الحجم والصيغة |
| **الإعلانات والمتعقّبات** | `AdHosts` (مضمّنة) | لا شيء |
| **DoH** | `DohHosts` | لا شيء |
| **SafeSearch** | `SafeSearchHosts` (إعادة كتابة، لا حجب) | لا شيء |
| **قائمة المستخدم** | قاعدة البيانات (جدول `protected_days` المجاور + جدول العناصر) | فوري |

الواجهة: **قائمة الحجب** (`/blocklist`) — مواقع / تطبيقات /ميزات، مع بحث وتصفية.

### 1.3 حجب التطبيقات

| | |
|---|---|
| **الوظيفة** | يكتشف التطبيق في المقدمة ويعرض شاشة حجب كاملة |
| **الملفات** | `app/ui/intercept/InterceptActivity.kt`، `core/domain/block/AccessController.kt` |
| **الاستثناء** | `CriticalApps` — المشغّل، الإعدادات، الهاتف، الآلة، Sawn نفسه. **لا يُحجب أبداً** (قاعدة عدم قفل المستخدم خارج جهازه) |
| **الحالات** | مسموح / مسموح حتى وقت / موقوف / محجوب / بلغ الحد / محجوب تركيز عميق |
| **السطح** | شاشة الاعتراض (خلفية، زر «متابعة»، عدّاد) + إشعار «أُعيد فتح التطبيق» |

### 1.4 محرك المتصفحات (وضع خفيف)

| | |
|---|---|
| **الوظيفة** | يقرأ شريط العنوان في متصفح معروف، ويمنع الموقع إن كان محجوباً، ثم **يخرج من الصفحة** (يرسل BACK) |
| **الملفات** | `app/accessibility/BrowserBlockingEngine.kt`، `core/domain/block/web/` |
| **القيود** | لا يدخل WebView أبداً؛ يمشي 80 عقدة كحدّ أقصى؛ يقرأ الجزء المميّز من view-id ليشتغل مع كل متصفح |
| **السطح** | طبقة شفافة فوق المتصفح + زر «رجوع» تلقائي |
| **ملاحظات تصميم** | المحرك يقرأ النصّ المميّز لا محتوى الصفحة → لا خصوصية في القراءة |

### 1.5 قاعدة الحجب الخاصة بالعنصر (نافذة متكرّرة / رصيد مسموح)

| | |
|---|---|
| **الوظيفة** | يختار المستخدم التطبيق (أو الموقع) **والمدة**: نافذة متكرّرة (أيام + من/إلى) أو رصيد مسموح (دقائق يومياً). داخلها يُحجب التطبيق؛ خارجها يعمل كالمعتاد |
| **المواصفة** | [`docs/per-app-rule.md`](per-app-rule.md) — تسعة قرارات سلوكية |
| **السلوك** | القاعدة **تُجبِر** الحجب حتى مع إطفاء الحماية العامّة، ولا يمكن تعديلها قبل انتهاء فترتها الأولى، والهروب ٣ دقائق (يستهلك الرصيد) |
| **السطح** | قسم «القاعدة» في محرّر العنصر + شارة الحالة في قائمة الحجب |

### 1.6 ~~ما كان داخل التطبيقات~~ — حُذف من المنتج

حجز شرائح التطبيقات (Reels/Shorts/TikTok)، وكشف المحتوى الاجتماعي داخل التطبيقات،
والفحص البصري للمحتوى (NSFW): **أُزيلت كلها**. التطبيق لا يقرأ نصّ الشاشة ولا
يلتقط صورة، ولا يمرّ على محتوى أي صفحة — وعد الخصوصية صار أبسط وأقوى.

### 1.7 المحركان معاً — أين تُحجب المواقع

| | فلترة DNS | محرك المتصفح |
|---|---|---|
| **يعمل على** | الأسماء | شريط العنوان |
| **يصطاد** | كل متصفح وWebView وتطبيق | المتصفحات المعروفة فقط |
| **يحتاج إذن VPN** | نعم | لا |

الوضع **متقدّم** = الاثنان (الأقوى). الوضع **عادي** = الثاني فقط (بلا إذن).

## 2. القواعد والظروف —Scheduling

| القاعدة | الملف | الأثر |
|---|---|---|
| **المفتاح الرئيسي** | `BlockingPolicy` | كل شيء |
| **الجداول** | `ScheduleEvaluator` | نافذة زمنية (أيام + دقائق)؛ نافذة تعبر منتصف الليل تخصّ اليومين |
| **جلسة التركيز** | `StrictPolicy` | نافذة بيضاء/سوداء + صلابة |
| **التركيز العميق** | `DeepFocusPolicy` | قائمة بيضاء + مهلة خروج بعد PIN |
| **حارس الليل** | `NightGuardPolicy` | يفتح قفل PIN حتى الصباح |
| **سلسلة الأيام** | `ProtectionDayPolicy` | اليوم محسوب فقط إن كان الحجب فعّالاً |

**السطح**: الجداول (`/schedules`) — جدول/نطاقات/أيام/ساعات؛ حالة كل نافذة الآن (نشط/قادم).

**ثلاث طبقات لا تتعارض:**
- **البوابة (متى)**: المفتاح الرئيسي + (أيّ جدول نشط) — و**بلا جداول = حماية دائمة**. لا يوجد زرّ «دائماً مفعّل» بعد الآن: كان يلغي الجداول تماماً، فصار سلوكه ضمن القاعدة نفسها.
- **المحتوى (ماذا)**: قائمة الحجب + قواعد العناصر.
- **الإجبار (يُجبر)**: الأقفال + قاعدة العنصر + التركيز العميق — تتقدّم على البوابة دائماً.

**أثناء القفل: الحماية دائمة مهما كان الجدول** — يُقال للمستخدم صراحةً، لأن القفل يعلّق الجدول مؤقّتاً (ولا يلغيه).

## 3. الأقفال والانضباط —Locks

| القفل | المدة | يُلغى؟ | الملف |
|---|---|---|---|
| **القفل الزمني** | 1 دقيقة → 12 شهراً | **لا** — التمديد فقط | `LockdownPolicy` + `LockdownWindow` |
| **القفل الفوري (Panic)** | 15 / 30 / 60 دقيقة | **لا** — ولا يقصُر، ولا هروب | `EmergencyLockdown` |
| **حماية الإزالة** | دائم | لا — من إعدادات النظام فقط | `SawnDeviceAdminReceiver` |

| | |
|---|---|
| **السطح** | القسم «قفل صَوْن» في الرئيسية (القفل الزمني + الفوري)؛ PIN في `PinScreen` |
| **تفعيل القفل يطلب PIN** (إن كان PIN معرَّفاً) | القفل نفسه هو ما يمنع الإيقاف — فلا حاجة لوضع انضباط دائم |
| **حماية الإزالة تُفعَّل تلقائياً** مع القفل | بدل رفض القفل «لعدم توفّر الحماية» — القفل يبدأ، والنظام يطلب تفعيل الـadmin |
| **القفل الزمني يطلب إذن VPN** | القفل = حماية كاملة؛ إن اختار المستخدم «عادي» يمكنه تفعيل النفق وإيقافه متى شاء |
| **القفل الفوري لا يطلب إذن VPN** | لا مطالبة أبداً — لكنه **يشغّل الوضع المتقدّم تلقائياً** إن كان الإذن موجوداً، ويبقى المستخدم حرّاً في إطفائه بعد ذلك |
| **بلا هروب في القفل الفوري** | الهروب ٣ دقائق خاصّ **بقاعدة العنصر** فقط |
| **قفل التطبيقات (قاعدة العنصر) ميزة منفصلة** | لا يحتاج القفل الزمني ولا العكس: يمكنك قفل تطبيقاتك أثناء القفل أو بدونه |
| **المخرج الطارئ** | تعطيل الـadmin من النظام أو `force-stop` — مقصود (لا سجن) وموثّق في `SECURITY.md` |
| **وعد القفل** | «حجب التطبيق لا يمكن إيقافه» — لا «كل المواقع»: فلترة DNS تبقى خيار المستخدم (ما عدا لحظة تفعيل القفل الفوري) |
| **مناعة ضد عبث الساعة** | الأجل على ساعة رتيبة + علامة `high-water`؛ تغيير الساعة لا يُنهي القفل، وإعادة الإقلاع تعيد تثبيته |

**PIN**: `PinHasher` (PBKDF2، 310 ألف تكرار، ملح عشوائي) + `PinLockoutPolicy` (تراكم: 5 محاولات → 30s → ساعة، على ساعة رتيبة).

## 10. أسئلة مفتوحة قبل التصميم

1. **العدّاد في شاشة الحجب**: القفلان يعرضان الوقت المتبقي ✓ (القفل الزمني في البطاقة، والفوري في شاشته). ولا بدّ من عدّاد لقاعدة العنصر.
2. **ترتيب الرئيسية**: هل يبقى «كل شيء في صفحة واحدة»؟ الصفحة الحالية طويلة (مفاتيح + تقدّم + أدوات + أقفال + إدارة).
3. **لغة الأيقونات**: الأيقونات الحالية كلها Material؛ الهوية البصرية تحتاج قراراً (خط واحد؟ وزنان؟).
4. **الوضع الفاتح/الداكن**: `values-night` موجود — ما القاعدة التي تفصل بينهما اليوم؟
5. **البلاطتان**: هل تُدمجان في قائمة واحدة، أم تُبقيان منفصلتين؟
6. **نصّ القفل الفوري**: «يحجب كل التطبيقات» (لا «كل شيء») — يُصحَّح مع قرار بقاء فلترة DNS خياراً للمستخدم.
7. **موضع «القاعدة» في محرّر العنصر**: في النافذة نفسها أم خطوة منفصلة بعد اختيار التطبيق؟
